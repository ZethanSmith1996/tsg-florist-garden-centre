# TSG Florist Garden Centre — visual redesign

This is a **working static front-end prototype** based on the supplied homepage mock-up.

## Deploy to GitHub Pages

Upload the contents of this folder (not the enclosing folder or ZIP) to the repository root. In GitHub repository Settings → Pages, deploy from `main` and `/ (root)`.

## What's working
- Responsive homepage, mobile navigation, department links, category landing page, owner portal placeholder.
- All photography is stored locally in `assets/images`.

## Not yet connected
- Supabase products, stock, login, enquiries, checkout.
- Contact details have not been invented.

## Image note
The reference mock-up supplied by the owner was used to extract low-resolution visual crops. These are **temporary assets**. Replace them with original high-resolution storefront and product photography before public launch. The brand image is also a crop from the mock-up, not the original logo artwork.

## Files
- `index.html` — homepage
- `catalogue.html` — department placeholder pages using `?category=`
- `admin/index.html` — nonfunctional owner portal placeholder
- `assets/css/styles.css` — design and responsive styles
- `assets/js/main.js` — navigation and category titles
