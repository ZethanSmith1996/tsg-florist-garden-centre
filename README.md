# TSG Florist Garden Centre — Stage 2 preview

A static, responsive homepage for GitHub Pages. Includes the five agreed department placeholder pages and a non-functional admin landing page.

## Publish
Upload the **contents** of this folder to the root of the GitHub repository, then Settings → Pages → Deploy from a branch → main → /(root).

## Before launch
- Replace sample Unsplash images with licensed/owned photographs.
- Replace the `hello@example.com` placeholder contact link with the real business contact details.
- Confirm real address, opening hours, and business claims.
- Implement live catalogue from Supabase with verified RLS.
- Implement Supabase Authentication and administrator dashboard.
- Implement secure enquiry submission via an Edge Function.

The admin route is a placeholder and **does not** offer login or data editing yet. No service role or secret keys should ever be included in frontend files.
