# Stage 4.1.6.2
Back up the repository. Prefer a development branch or local testing first. Extract the ZIP and merge its contents into the repository root (not an extra nested folder). Existing prototype files are preserved. For local testing run `python3 -m http.server 8000` from the root, then open http://localhost:8000/admin/connection.html. Click Test connection. A successful Auth health response only verifies endpoint reachability; a non-2xx or CORS failure requires investigation. No SQL or secrets required. Do not treat this as a production till. GitHub Pages deployment is optional after local testing.
